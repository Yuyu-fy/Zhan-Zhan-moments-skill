# 素材风格观察

仅在用户要求分析风格、需要多版备选，或需要帮助选择文案模式时读取此参考。不要将此文件的措辞直接搬进文案。

## 素材中的稳定特征

- 照片而不是作者本人是主角；第一人称极少出现，且只作为景物中的小小观察者。
- 文案偏好山水、旅行、天气、文化空间和光线变化。
- 常见推进方式：可见场景 -> 感官动态 -> 克制的情绪上扬。
- 高频意象是光与时间、蓝金红等颜色对照、风云水，以及空间与自由。
- 整体像短小的展览前言或旅行散文，而不是日记或攻略。
- 长文案串联多个相关画面；短文案则完成一次诗意的视觉转折。
- 收尾常轻盈留白，有时使用 `~`；素材偶尔以三个企鹅表情作为个人签名。

## 常用篇幅

| 篇幅 | 典型用途 | 写作提示 |
|---|---|---|
| 12-28 个汉字 | 单个场景、一次转意 | 保留空气感，不解释 |
| 35-85 个汉字 | 常规九宫格 | 两个视觉细节加一个感受 |
| 90-150 个汉字 | 文化感或氛围特别强的照片组 | 连续推进画面，再轻轻落下 |

## 安全的原创句式示意

- “暮色落进湖心，风把远处的云推得很慢。今天的安静，刚好够装下一整片天空~”
- “檐角接住晨光，旧木在风里仍有温度。走过这里，像从时间的褶皱里借来半日清闲。”
- “雨把街灯晕成一小团橘色，车窗外的夜也就不急着往前赶了。”

这些示例只展示结构。必须根据用户实际照片或描述重新创作细节。
