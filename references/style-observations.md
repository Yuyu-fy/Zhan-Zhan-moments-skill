# 素材风格观察

仅在用户要求分析风格、需要多版备选，或需要帮助选择文案模式时读取此参考。不要将此文件的措辞直接搬进文案。

## 稳定审美与变化表达

素材的共同点不是每条都写风景，而是“有审美、有自我、略带偶然”。稳定的是从真实细节出发的诗性转译；变化的是篇幅、句式、题材和收尾方式。

- 旅行和风景多写光线、色彩、风、水与空间感。
- 人物和日常可以写笑声、动作、食物、车窗、试卷或场所中的小物件。
- 常见推进方式：用户经历/可见场景 -> 感官动态或意外观察 -> 克制的情绪收束。
- 文案像短小的展览前言、旅行散文，或忽然想到的一句轻松感叹，而不是攻略或日记。
- `~` 和企鹅表情是偶发的语气工具，不是固定签名。

## 提示词优先的选材顺序

按下列优先级选材：

1. 用户明确说明的事件、人物、关系、地点、时间和感受。
2. 用户明确想公开或不想公开的内容。
3. 图片中可确认的画面细节。
4. 为连接前述信息而原创的意象。

不要反过来让图片决定文案主题。没有图片时，以用户的事件、人物动作、对话或感受建立画面。

## 常用篇幅

| 篇幅 | 典型用途 | 写作提示 |
|---|---|---|
| 12-28 个汉字 | 一次转意、短题记 | 留出空气感，不解释 |
| 35-85 个汉字 | 普通旅行、相逢、日常分享 | 一个事实锚点加一层感受 |
| 90-150 个汉字 | 文化场所、重要纪念、丰富的经历 | 连续推进细节，再轻轻落下 |

## 安全的原创句式示意

- “散场的人群还没走远，今天的欢呼已经替这座城市落了款～”
- “聊到忘了时间，才发现异乡的熟悉，有时比想象中来得更快。”
- “试卷合拢，晚饭登场。今天的紧绷，终于被一桌热气慢慢接住。”

这些示例只展示结构。必须根据用户本次提示重新创作事实与细节。
