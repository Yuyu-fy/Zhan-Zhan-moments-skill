# 詹詹朋友圈文案

把旅行见闻、人物相逢、约会纪念、校园生活与日常感触，写成一条有画面感、有留白的中文朋友圈文案。

`zhan-zhan-moments-skill` 是一个面向 Codex 的创作 Skill。它以用户提供的事件、人物、情绪和分享意图为主要依据；图片仅用于补充可见细节，不是必需输入。它生成简短、克制且可以直接发布的朋友圈正文，不写成行程记录、景点介绍或空泛的“治愈系”套话。

## 适用场景

- 旅行、山水、城市与风景见闻
- 建筑、老城、书局、展馆与文化空间
- 朋友同行、人物相逢、约会与纪念日
- 比赛、演出、聚餐、校园生活与日常随拍
- 已有朋友圈文案的精简与风格润色

本 Skill 不以旅游攻略、事实查询、营销推广或逐张看图说明为目标。

## 核心能力

- **提示词优先**：先识别事件、人物关系、情绪、分享边界与表达意图。
- **图片可选补充**：有图片时提取画面细节；没有图片时也能直接生成。
- **自适应模式**：根据旅行、相逢、文化场所、热闹现场、纪念日常等经历选择写法。
- **三步写作推进**：落到专属细节，完成诗性转译，再留下克制的情绪余韵。
- **原创意象**：根据本次经历创造比喻和拟人，不复用素材中的标志性句子。
- **few-shot 风格参考**：创作前参考 `assets/copywriting.md` 中的文案素材，观察构图、节奏与留白；只模仿结构，不复制原句。
- **事实约束**：不虚构地名、历史、人物关系或用户没有提供的经历。
- **反模板检查**：过滤流水账、口号、辞藻堆砌和机械重复的句式。

## 工作方式

```text
用户提示词
    ↓
提取事件、人物与情绪
    ↓
可选：从图片补充细节
    ↓
可选：参考 few-shot 素材（模仿结构，不复刻原句）
    ↓
画面 → 动态 → 余韵
    ↓
原创性与事实检查
    ↓
一条可直接发布的正文
```

用户给出“事件 + 至少一个具体细节 + 情绪”时，Skill 会直接生成。信息不足时，才简短询问发生了什么、和谁、以及最想留下的感受。

## 快速开始

### 1. 安装

下载仓库后，保留完整目录结构，将项目文件夹放入 Codex 的个人 Skills 目录：

```text
~/.codex/skills/zhan-zhan-moments-skill/
```

安装后的关键文件应保持如下结构：

```text
zhan-zhan-moments-skill/
├── SKILL.md
├── assets/
│   └── copywriting.md
├── agents/
│   └── openai.yaml
└── references/
    └── style-observations.md
```

### 2. 调用

直接描述经历即可；图片可选，然后在请求中使用 Skill 名称：

```text
$zhan-zhan-moments-skill 为这次英国旅行写一条朋友圈文案。
我们三个同学参观了哈利波特华纳制片厂，和店员 Nimo 聊得很投机，想写得温暖一点。
```

也可以直接提出自然语言请求：

```text
请用詹詹的朋友圈风格，把我看完球赛后仍很兴奋的感受写成一条简短文案。
```

## 输入建议

为了让文案更贴合这次经历，可以提供以下信息：

- 发生了什么
- 和谁一起，哪些人物或关系可以公开
- 大致地点、时间或场所
- 想表达的情绪
- 希望保留或避免的信息
- 长度、表情和备选数量偏好

不必一次写全。事件、一个具体细节和情绪已经足够；若提供图片，Skill 会将其中可确认的画面作为补充。

## 示例

输入：

```text
在英国旅行时参观了哈利波特华纳制片厂，和当地店员聊得很投机。想写得温暖、轻松一些。
```

输出：

```text
片场的灯光还亮着，一场意外投机的聊天，替这段旅程添了一页温暖的番外～
```

默认只输出一条完成稿，不添加“朋友圈文案：”等标签。用户明确要求时，才会提供多版备选或解释写作思路。

## 设计原则

1. **提示词先于图片**：每条文案首先准确承接用户的事件、人物和情绪。
2. **细节支撑情绪**：图片可补充画面，但不凭空拔高，不把普通经历硬写成宏大哲思。
3. **文学感不等于堆词**：每条只使用少量有效修辞。
4. **借鉴结构，不复制原句**：保留观察方式，同时确保输出原创。
5. **文案与照片并列**：不重复解释照片，而是为画面补上一层余韵。

完整规则见 [SKILL.md](./SKILL.md)，素材特征摘要见 [style-observations.md](./references/style-observations.md)。

## 项目结构

- `SKILL.md`：触发条件、写作流程、输出规则和质量检查。
- `assets/copywriting.md`：詹詹的文案素材，作为 few-shot 示例，供模仿结构与审美。
- `agents/openai.yaml`：Skill 的展示名称、简介和默认调用提示。
- `references/style-observations.md`：从素材中提炼的稳定风格特征与篇幅参考。

## 隐私与原创

- 上传人物照片前，请确认拥有相应的使用权限，并避免提交不必要的敏感信息。
- 生成结果应在发布前由用户自行核对人物、地点、日期和事实。
- 本项目学习的是构图观察、语言节奏和写作方法，不鼓励逐句复制素材或冒充真实人物发布未经确认的经历。

## 反馈与贡献

- 与用户经历不匹配或过于模板化的输出

修改写作规则时，请同时检查旅行、人物相逢、比赛演出、文化空间、纪念日常等不同场景，避免只针对单个示例过拟合。
